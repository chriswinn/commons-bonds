# Library list: sources a session cannot reach (running)

**Status:** internal; running list. Started 2026-11-15. Any session that hits a source it cannot read adds a
row here **only after testing access** (say how it was tested). When the author brings a source back, the
session reads it, writes the extracts into a note in `research/citations/`, and strikes the row with the date.

**How access was tested (2026-11-15).** A plain request to each address from the cloud session, whose network
is unrestricted. "Blocked" means the site itself refused (login, paywall or a filter against automated
requests). For books, the Internet Archive's scans were checked: all are lending-only and refuse a download.
Unofficial uploads of some of these books exist online; sessions do not use them.

**How to bring sources back.**
- **Journal articles:** download the PDF from the library database and attach it to a session message, or
  put it in the Drive folder that holds the Butler printout and give the session the file name. Do not paste
  a database link: library links only work on the library's network.
- **Books:** you do not need the whole book. Photograph or scan the pages listed, plus the title page and the
  copyright page (for the edition), with page numbers visible. Phone photos are fine. If the library has the
  e-book, copying the passage as text with its page number is quicker still.
- **Nothing copyrighted goes into the repository.** The session reads it and commits only short extracts with
  page numbers, as was done for Butler.
- **Skip any row whose sentence you decide to cut.** Each row names the claims-check item it settles
  (`tools/audits/claims-check_chapter-5_2026-11-15.md`).
