## How to delete safely

Tag every branch first (`archive/2026-11-10/<branch>`), then delete the branch. Tags keep every commit
retrievable and can be turned back into a branch in one command, while the branch list stops showing them.
Nothing in the table needs to come back for the book plan; the four "(tag)" rows are the only ones with even
marginal value (old essay drafts a December redraft could glance at).
