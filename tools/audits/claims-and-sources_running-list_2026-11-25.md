**The four kinds of next step.**

| Code | Meaning | Who moves it |
|---|---|---|
| **APPROACH** | The sources do not support the passage as built. A new sentence will not fix it; the book has to decide what the passage is for and how to stand it up. | Author, with a session's options |
| **SOURCE** | A source may exist and has not been read. | Session first; author only where the list says so |
| **REWORD** | The source is in hand and says less than the text. A supported sentence is already drafted in the report. | Author rules, usually "as recommended" |
| **REVISIT** | A ruling already given that later evidence reopens. | Author |
