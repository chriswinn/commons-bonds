# Source harvest for Chapters 2–4 and 6–10 (step 1 of the sources-first plan)

**Status:** internal; 2026-11-26. Replaces the machine first pass
(`sources-inventory_ch2-4_ch6-10_first-pass_2026-11-26.md`).

**What this is.** A list of what each chapter intends to lean on: named thinkers and their works, cases,
public records, and quoted people. It is a harvest, not a claims check. It was made from the names, titles
and institutions in both November 14 drafts of each chapter, with each new author's sentence read to see
which work is meant. **Its limit:** it lists what the drafts name. A fact stated with no name attached (a
date, a figure) is not here; those come out when each chapter's fact table is pinned (step 3).

**The plan this serves** (author, 2026-11-26: get the sources before drafting): 1 harvest; 2 request and
fetch; 3 read and build a pinned fact table (fact, source, page, exact words); 4 draft from the table only;
5 a light claims check before his redline.

**Key.** R = requested through the library. Read = held and read at the passage. Free = a session can fetch.
PD = out of copyright. New = found by this harvest and requested today.
